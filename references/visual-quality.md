# Visual Quality

## 从需求创作

先确定受众、用途、画面比例、阅读距离和一个记忆点。信息图/课件优先原生 shapes；视觉发散确实必要时可先生成 concept，但 concept 只是 art direction，不能作为不可编辑背景冒充交付。

拆成语义模块：背景、主对象、辅助对象、文字、连接、图例、控制、状态反馈。每个可能被用户修改的文字和颜色角色保持独立。

## 参考图复刻

1. 检查源图实际像素、比例、裁切和需排除的界面/水印。
2. 记录背景、大块区域、主轮廓、文字基线、中心线、边距、重复间距。
3. 从源像素取样主色、阴影、描边和高光；不要凭记忆替换“相近色”。
4. 从大到小搭建：artboard → 主几何 → 文字 → 轮廓 → 精细细节。
5. 在相同 crop / scale 下比较 live canvas；按裁切、主几何、对齐、色板、字体、细节顺序修正。
6. 修改并恢复一个文字、一个颜色、一个几何元素，证明真实可编辑。

“像素级”“完全一致”是比较结果，不是默认承诺。没有同裁切 live evidence 时使用“接近参考”并说明差异。

## 视觉检查表

- 一眼能否识别主路径或主对象。
- 标题、主体、注释是否有明确层级。
- 文本没有裁切、溢出、意外换行或低对比度。
- 箭头不穿过文字，不在节点边缘堆叠。
- 控件有 default、hover/active、selected/disabled 等必要反馈。
- 截图来自真实 tldraw window，不是设计 mockup。
- 画布中没有源图 bitmap 冒充可编辑重建。
